# IMG_3762 style bible

Use this file when deciding whether a result belongs to the master style. The bundled image is a photographed reference sheet; the artwork language is the source of truth, not the surrounding photograph.

## Visual identity

The style is a small-object diary doodle drawn with black ink on white paper. It combines a loose contour drawing with sparse graphic black fills. The result should feel like a person quickly but intentionally drawing familiar food and daily-life objects in a notebook. Use `assets/style-master-sheet.png` as the cleanest bundled visual reference.

## Shape language

- Simplify objects into a readable silhouette with a few defining features.
- Favor soft, organic curves and mildly imperfect symmetry.
- Allow slightly naive proportions and small playful distortions.
- Use simple perspective only when it helps identify a cup, plate, tray, cake, fruit, or utensil.
- Avoid hard geometric construction, technical precision, and photorealistic volume.

## Line language

- Use black ink contours with mild wobble and local pressure variation.
- Let some contours be delicate and others become heavier at overlaps or emphasis points.
- Prefer rounded caps and organic joins.
- Keep the contour readable at small size; do not replace it with hairline noise.
- Avoid perfectly uniform vector strokes and smooth digital calligraphy.

## Fill and texture language

- Fill only selected dark areas with near-solid black: deep shadows, dark cups, fruit skins, ribbons, plate undersides, or accent regions.
- Use a few short interior strokes, dots, or sparse hatching to suggest texture.
- Keep texture subordinate to the silhouette.
- Do not use gray shading, airbrush gradients, colored-pencil grain, watercolor washes, halftone backgrounds, or dense crosshatching.

## Composition language

- For one asset, center a single object with generous empty space.
- For a set, keep objects visually independent and consistently scaled.
- Use plates, saucers, trays, or a small grounding shadow only when they support the subject.
- Keep the visual weight calm and balanced; do not create a busy scene.
- Treat labels as optional layout elements, not part of the core object drawing.

## Forbidden drift

Reject results that look like any of the following:

- clean SVG icon or logo;
- coloring-book outline with no black accents;
- realistic photo tracing;
- anime, manga, comic-book, or cartoon rendering;
- watercolor, colored pencil, pastel, crayon, or charcoal;
- polished 3D illustration;
- dense botanical engraving or technical patent drawing;
- a photographed notebook page with UI bars, desk, cloth, frame, or watermark.

## Reference-sheet interpretation

The reference contains both fine contours and stronger black fills. Keep the common language fixed, but use the following priority order for a stable default:

1. recognizable simplified silhouette;
2. organic black contour;
3. selective black fill;
4. sparse dots or short hatching;
5. generous white space.

Never trade away the silhouette or contour in order to add texture.
